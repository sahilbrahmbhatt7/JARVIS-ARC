# JARVIS ARC - AI Virtual Assistant

JARVIS ARC is a Python-based AI Virtual Assistant designed to perform voice-controlled tasks, system automation, and intelligent assistant operations through a modern web interface.

## Features

- Voice Recognition
- Text-to-Speech
- AI Chat Support
- System Automation
- Open Applications
- Open Websites
- File Management
- OSINT Module
- Modern Web Interface

## Tech Stack

- Python
- Eel
- HTML
- CSS
- JavaScript
- SQLite

## Project Structure

```
JARVIS-ARC/
```

## Installation

1. Clone the repository

```bash
git clone https://github.com/sahilbrahmbhatt7/JARVIS-ARC.git
```

2. Open the project

```bash
cd JARVIS-ARC
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the project

```bash
python run.py
```
